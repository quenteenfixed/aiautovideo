# AI Auto Video — 分镜提示词

## 使用方法

将以下提示词和你的原始文案一起发送给大模型（ChatGPT / Claude / 豆包 等），大模型会输出一个 JSON，保存为 `.json` 文件后直接用于视频渲染。

---

## 提示词模板

```
你是一个专业的科普短视频分镜师。请将以下原始文案转换为结构化的 script.json 格式。

要求：
1. 将文案拆分为 5-8 个场景（scene），每个场景对应一段旁白
2. 第一场景必须是"开头三秒爆款"（钩子），最后场景是结尾引导
3. 根据内容自动选择视觉类型：
   - text_card: 概念解释、观点陈述
   - chart: 涉及数字、数据对比、百分比的内容（必须提取真实数据构建图表）
   - animation: 涉及实验、过程、机制的内容
   - image: 场景描述、背景介绍
4. 每个场景提取简洁标题（不超过15字）
5. 根据中文语速（约5字/秒）估算每个场景的合理时长
6. 选择合适的转场效果
7. 结尾场景(outro)要有引导关注的内容

输出格式严格如下（JSON，不要加 markdown 代码块标记）：

{

  "title": "标题",
  "resolution": { "width": 1080, "height": 1920 },
  "fps": 30,

    "bg_color": "#0F1923",
    "text_color": "#E0E7FF"
  },
  "voice": {
    "provider": "edge-tts",
    "voice_name": "zh-CN-YunxiNeural",
    "rate": "+10%",
    "pitch": "+0Hz",
    "volume": "+0%"
  },
  "subtitle_style": {
    "font_size": 42,
    "font_family": "Noto Sans SC, sans-serif",
    "color": "#FFFFFF",
    "highlight_color": "#F5A623",
    "stroke_color": "#000000",
    "stroke_width": 3,

    "position": "bottom",
    "offset_y": 180,
    "max_width": 900
  },
  "scenes": [
    {
      "scene_id": 1,
      "narration": "旁白文字（直接使用原文内容，不要改写）",
      "duration": 10,
      "visual": {
        "type": "text_card",
        "title": "场景标题（简洁，15字内）",
        "subtitle": "副标题（可选）",
        "animation": "fade_in_zoom"
      },
      "transition_in": "fade",
      "transition_out": "slide_left"
    },
    {
      "scene_id": 2,
      "narration": "...",
      "duration": 18,
      "visual": {
        "type": "chart",
        "chart_type": "bar",
        "data": {
          "title": "图表标题",
          "labels": ["标签1", "标签2", "标签3"],
          "values": [30, 60, 45],
          "y_axis_label": "Y轴标签"
        },
        "animation": "fade_in",
        "components": [
          {
            "type": "badge",
            "text": "关键数据标注",
            "position": "top_center",
            "color": "#F5A623"
          }
        ]
      },
      "transition_in": "slide_left",
      "transition_out": "slide_up"
    }
  ],
  "outro": {
    "duration": 8,
    "narration": "结尾旁白",
    "visual": {
      "type": "cta_card",
      "text": "引导关注的文案",
      "animation": "fade_in_zoom"
    },
    "transition_in": "fade"
  }
}

可选的视觉类型：
- text_card: 文本卡片（标题+副标题+动画）
- chart: 图表（bar/line/pie/scatter/radar/spectrum）
- animation: 动画演示
- image: 图片展示（ken_burns/parallax/static）
- mixed: 混合布局

可选的转场效果：
fade, slide_left, slide_right, slide_up, zoom_in, zoom_out, wipe, bounce, none

可选的动画效果：
fade_in_zoom, slide_up, bounce_in, fade_in

可选的模板风格：
data_visual_style（深色数据感）, illustration_style（暖色插画）, cinematic_style（暗色电影）, minimal_style（极简白）, infographic_style（信息图）

以下是原始文案：

【在此粘贴你的原始文案】
```

## 完整工作流

```
步骤 1: 大模型分镜
  - 复制上方提示词 + 原始文案 → 发送给大模型
  - 将大模型输出的 JSON 保存为 scripts/football_006.json

步骤 2: 校验脚本
  bash scripts/start-local.sh generate scripts/football_006.json

步骤 3: 渲染视频
  bash scripts/start-local.sh render scripts/football_006.json

步骤 4: 查看 output/football_006/football_006.mp4
```
